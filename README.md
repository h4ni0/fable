# Fable

A collection of small experiments and prototypes.

## Linked Projects

These projects live in their own repositories and are linked here as Git submodules:

- [obsidian-web](https://github.com/h4ni0/obsidian-web) at `obsidian/`
- [OS](https://github.com/h4ni0/OS) at `OS/`
- [video-editor](https://github.com/h4ni0/video-editor) at `video-editor/`

Clone this repository with submodules:

```bash
git clone --recurse-submodules https://github.com/h4ni0/fable.git
```

If you already cloned it:

```bash
git submodule update --init --recursive
```
